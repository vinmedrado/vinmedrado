# Demo assets

Este diretório existe para organizar GIFs curtos de demonstração dos projetos.

Padrão de nomes sugerido:

- `01-open-home.gif`
- `02-login-or-entry.gif`
- `03-core-flow.gif`
- `04-dashboard.gif`
- `05-automation-or-ai.gif`

Para manter os arquivos leves:

- duração ideal: 10 a 20 segundos;
- capturar em 1x;
- cortar pausas e scrolls desnecessários;
- exportar com compressão moderada;
- priorizar fluxo completo em vez de clipes longos.

Roteiro sugerido por projeto:

## marketplace-seller-platform

1. Abrir o produto.
2. Navegar até o dashboard principal.
3. Mostrar um fluxo de precificação ou análise.
4. Encerrar na visão de resultado.

## applymize

1. Abrir a landing ou tela principal.
2. Mostrar busca ou análise de vagas.
3. Exibir automação ou recomendação de IA.
4. Encerrar no acompanhamento de candidatura.

## Lumyra

1. Abrir a home.
2. Mostrar RSVP ou operação de eventos.
3. Abrir dashboard / mapa / financeiro.
4. Encerrar em uma automação ou realtime.

## football-decision-lab

1. Abrir a interface principal.
2. Mostrar coleta / validação temporal.
3. Abrir backtest ou previsões.
4. Encerrar em evidência de experimento.

## vinance

1. Abrir a home / dashboard.
2. Mostrar orçamento ou visão executiva.
3. Abrir insights financeiros ou IA.
4. Encerrar em uma recomendação clara.

## meu-carro-vale

1. Abrir a experiência principal.
2. Mostrar avaliação do veículo.
3. Abrir comparáveis, FIPE ou laudo.
4. Encerrar na faixa recomendada.

## portfolio

1. Abrir a landing page.
2. Mostrar navegação entre projetos.
3. Abrir um projeto externo.
4. Encerrar com contato / CTA.
