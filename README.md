## How I approach engineering

- **Data quality:** validate inputs and outputs before publishing reports or downstream datasets.
- **Automation:** optimize repetitive processes while keeping error handling and observability visible.
- **Maintainability:** separate domain logic, data access and user interfaces.
- **Testing:** use automated checks to prevent regressions, while documenting what they do *not* cover.
- **Privacy:** isolate public demos from real accounts, tokens and sensitive data.

The projects are portfolio and learning initiatives; their passing CI checks do **not** imply exhaustive security testing or production certification.
